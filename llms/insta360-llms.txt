# Insta360

> Insta360 (Arashi Vision Co., Ltd) makes consumer and professional 360-degree and action cameras. Its developer program exposes on-device HTTP control APIs and native SDKs so third-party apps can connect to, configure, capture from, and pull media off Insta360 cameras. The consumer cameras implement Google's Open Spherical Camera (OSC) API; the Pro/Titan line adds a JSON-over-HTTP command API. Native C++, Android, and iOS SDKs wrap camera control and media stitching/editing.

## APIs

- [OSC API](https://github.com/Insta360Develop/Insta360_OSC): HTTP/JSON control API for consumer 360 cameras, based on Google Open Spherical Camera. Camera reachable at 192.168.42.1 over its Wi-Fi AP.
- [Pro Camera API (ProCameraApi)](https://github.com/Insta360Develop/ProCameraApi): JSON-over-HTTP command API for Insta360 Pro / Pro 2 / Titan cameras (osc/commands/execute, osc/state, file access, RTMP preview).

## SDKs

- [Desktop CameraSDK (C++)](https://github.com/Insta360Develop/Desktop-CameraSDK-Cpp): C++ library to control Insta360 cameras.
- [Desktop MediaSDK (C++)](https://github.com/Insta360Develop/Desktop-MediaSDK-Cpp): C++ library for stitching and editing Insta360 media.
- [Android SDK](https://github.com/Insta360Develop/Android-SDK): integrate Insta360 cameras into Android apps.
- [iOS SDK](https://github.com/Insta360Develop/iOS-SDK): integrate Insta360 cameras into iOS apps.
